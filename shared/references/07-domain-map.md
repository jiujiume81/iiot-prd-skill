# 领域地图：13 个系统与 17 个交接断点

> 三条原则：**不写功能只写边界**、**只写会断的地方**、**每条都是可检索的条目不是段落**。

## 一、系统边界（一句话：管什么 / 不管什么 / 上下游）

| 系统 | 管什么 | 明确不管 | 主要上游 | 主要下游 |
|---|---|---|---|---|
| ERP | 订单、采购、库存账、成本、财务 | 工序、检验判定 | 销售订单、采购申请 | WMS、MES、QMS |
| APS | 排产、产能、交期承诺 | 执行、物料实物 | ERP 订单、工艺路线、设备产能 | MES |
| MES | 工单执行、工序流转、报工、在制追溯 | 质量判定规则、库存账 | APS 工单、WMS 发料 | WMS、QMS、SPC、EAM |
| SCADA | 设备实时采集、报警、组态 | 业务单据、判定 | PLC / 仪表 | MES、SPC、ANDON |
| PLC | 设备逻辑控制、工艺参数执行 | 数据存储、业务语义 | 上位机指令 | SCADA |
| WMS | 收货、上架、库位、发料、盘点、批次账 | 检验、工单工序 | ERP 收货指令、QMS 放行结论 | MES、ERP |
| QMS | 检验标准、检验任务、判定、不合格处置、CAPA | 库存实物、工序执行 | MES/WMS 检验委托、LIMS 数据 | WMS、MES、SRM |
| LIMS | 样品登录、任务分派、仪器采集、报告 | 生产工序、库存 | QMS 委托、MES 取样点 | QMS |
| SPC | 控制图、过程能力、超限报警 | 判合格与否（判的是过程稳定） | PLC/SCADA、QMS 检验值 | QMS、MES |
| SRM | 供应商主数据、订单协同、来料预约、绩效 | 来料检验判定 | 采购订单 | WMS、QMS |
| EAM | 设备台账、点检、保养、维修、备件 | 生产工单、工艺参数 | MES 设备状态、SCADA 报警 | MES、WMS |
| PLM | 物料主数据、BOM、工艺路线、图纸、变更 | 执行版本的实际使用 | 设计变更 | ERP、MES |
| ANDON | 异常呼叫、响应、升级、停线 | 根因分析、处置单据 | 工位按钮、设备报警、MES | MES、EAM |
| 追溯系统 | 正反向追溯、批次父子关系、留档 | 业务过程本身 | MES/QMS/WMS 全量事件 | 客审、召回、法规报表 |

## 二、交接点与常见断点（本 skill 最值钱的一张表）

| # | 交接 | 交接物 | 关键字段 | 常见断点 |
|---|---|---|---|---|
| 1 | QMS → WMS | 检验判定结论 | 批次号 / 判定 / 判定时间 / 报告号 | **WMS 没有「待检」库存状态**，货先进了可用库存，判定出来时已被领用 |
| 2 | QMS → MES | 工序放行 | 工单号 / 工序号 / 放行结论 | 首件不合格但工单已报工，MES 不知道要停 |
| 3 | LIMS → MES | 样品与工单绑定 | 样品号 / 工单号 / 工序号 / 取样点 | 样品只登批次号没登工单号，追溯找不到是哪张工单的料 |
| 4 | LIMS → QMS | 检验结果 | 样品号 / 项目 / 实测值 / 单位 / 检出限 | 检出限没传，「<0.01」被当成 0.01 存 |
| 5 | SPC 数据源 | 控制图原始值 | 点位 / 时间戳 / 值 / 采集方式 | 从 PLC 采和从检验记录来是两套数，同工序两条控制图对不上，CPK 算出两个值 |
| 6 | MES → WMS | 物料消耗 | 工单号 / 物料 / 批次 / 数量 | 倒冲时批次由系统按 FIFO 猜，现场拿的是另一批，账实不符且追溯错 |
| 7 | WMS → MES | 发料 | 发料单 / 批次 / 库位 | 一次发料分多次上料，MES 只记第一次的批次 |
| 8 | ERP → WMS | 收货指令 | 采购单 / 供应商 / 数量 | 超收短收容差在 ERP 定，WMS 不知道，收货卡住 |
| 9 | SRM → QMS | 供应商批次与 COA | 供应商批次号 / COA / 到货时间 | **供应商批次号规则各家不同且会变**，无法用它做抽检频次基准 |
| 10 | APS → MES | 工单与工序计划 | 工单号 / 工序 / 计划起止 / 设备 | 插单后 APS 重排，MES 已开工的工序不跟着变 |
| 11 | MES → APS | 实际进度 | 完工数 / 报废数 / 实际工时 | 报工滞后，APS 按计划推，越推越偏 |
| 12 | EAM → MES | 设备停机 | 设备号 / 停机起止 / 原因码 | 保养时段与工单计划冲突，MES 仍按有设备排产 |
| 13 | MES → EAM | 设备运行 | 运行时长 / 产量 / 报警 | 一台设备做多个工单，运行时长按工单分摊的规则没定 |
| 14 | PLC → MES | 产量计数 | 设备号 / 计数 / 时间 | 一个循环多件、一模多穴，按信号次数算产量必然少算 |
| 15 | PLM → MES | 工艺路线 / BOM 版本 | 物料号 / 版本 / 生效时间 | 变更生效时点在制工单用旧版还是新版，没人定 |
| 16 | ANDON → MES | 停线 / 恢复 | 工位 / 停线原因 / 起止 | 停线期间已报工产量没扣，OEE 算出超过 100% |
| 17 | 追溯 ← 全系统 | 批次父子关系 | 父批次 / 子批次 / 转换关系 / 数量 | 拆批、并批、让步接收三种情况的父子关系各系统各写一套 |

## 三、怎么用

- 画 M4 时，每画到一个跨系统步骤，回这张表查一次「这一步的交接物有没有断点」。查到就在 M5 落一条异常。
- 做 M1 时，用「明确不管」列去砍非目标：系统 A 不管的东西，不要在本次需求里让它管。
- 做 M2 时，交接点两端通常是两个角色，容易漏掉「下游等待者」（仓库等判定、产线等放行）。

## 四、四类最常被当成"同一个东西"的概念

| 容易被混为一谈 | 实际差别 | 后果 |
|---|---|---|
| 检验判定 vs 过程判定 | 一个是产品合格，一个是过程稳定（SPC） | 把 CPK 不达标当成产品不合格，误判退货 |
| 报工 vs 产量采集 | 一个是人报，一个是设备计数 | 一模多穴时产量少算 3/4 |
| 让步接收 vs 降级使用 | 前者是判定结论，后者是用途变更 | 让步批流到客户手里没标识 |
| 批次号 vs 收货流水号 | 前者供应商给，后者自己生成 | 断号时抽检基准失效 |
